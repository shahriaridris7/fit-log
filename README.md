


FitLog – Workout Library & Planner

FitLog is a responsive workout management web application where users can browse exercises, add workouts to their daily plan, save favorite workouts, mark exercises as completed, and track basic workout metrics.


# Technologies Used
. Next.js

. React

. TypeScript

. Tailwind CSS

. React Context API

. REST API

## Features

-  Workout library
-  Add workouts to today's plan
-  Save workouts for later
-  Mark workouts as completed
-  Remove workouts from your plan or saved list
-  Workout metrics:
  - Exercises
  - Minutes
  - Calories
-  Responsive design for mobile, tablet, and desktop
-  Dark-themed UI
